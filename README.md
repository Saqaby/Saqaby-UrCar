# سيارتك · UrCar

واجهة رئيسية عربية لشاشة أندرويد في السيارة (head unit): ساعة، تاريخ هجري، مواقيت الصلاة حسب موقع GPS الحالي،
نافذة رمضان، آية/حديث/قول من أقوال السلف، وأربعة اختصارات كبيرة: الملاحة، الموسيقى، الهاتف، إذاعة القرآن.

## المرحلة الحالية: معاينة HTML

- افتح `dist/urcar.html` في المتصفح (يعمل بلا إنترنت؛ الإذاعة والأذان يحتاجان إنترنت).
- البناء: `python3 src/build.py` ← `dist/urcar.html` و`dist/artifact.html`.
- شريط المعاينة أعلى الصفحة: مقاس الشاشة، الموقع (أو GPS)، جهة السائق، ومحاكاة «قبل الأذان» و«يوم في رمضان».

لم يُكتب كود أندرويد بعد؛ ينتظر مراجعة المعاينة.
