# سيارتك · UrCar

واجهة رئيسية عربية لشاشة أندرويد في السيارة (head unit): نافذة ملاحة كبيرة (يُختار تطبيقها من الإعدادات)،
وبجانبها بطاقة بصفحتين (الصلاة القادمة، والتحكم بآخر تطبيق صوت) وأربعة أزرار: يوتيوب، البلوتوث، الإعدادات، التطبيقات.

## المرحلة الحالية: معاينة HTML

- افتح `dist/urcar.html` في المتصفح (يعمل بلا إنترنت؛ الإذاعة والأذان يحتاجان إنترنت).
- البناء: `python3 src/build.py` ← `dist/urcar.html` و`dist/artifact.html`.
- شريط المعاينة أعلى الصفحة: مقاس الشاشة، الموقع (أو GPS)، ومحاكاة «قبل الأذان» و«يوم في رمضان». جهة السائق وتطبيق الملاحة في «الإعدادات».

لم يُكتب كود أندرويد بعد. الخطوة التالية فحص الشاشة: `docs/PROBE-PROMPT.md` (القواعد في `AGENTS.md`).
